# Rice Purity Test

A standalone static site with a 100-question quiz, score guide, FAQs, and a custom WebP banner.

## Run and deploy

Open index.html directly in a browser. For deployment, upload index.html, quiz.js, robots.txt, sitemap.xml, and the entire assets folder to a static host. No build step, installation, or backend is required.

Production metadata, structured data, and the sitemap use https://ricepurity-test.app/. Update these URLs if hosting on another domain.

## Privacy and assets

Quiz answers remain in the page. There are no analytics, advertising scripts, accounts, cookies, or external runtime dependencies. Styles, fonts, and images require no third-party service.

The original layout and questionnaire have been retained, with a refreshed banner and site icons. Retaining this material does not establish original authorship or exclusive ownership.

The banner was refreshed using the built-in image tool with a classic black serif title, transparent background, and a small red underline. Responsive WebP variants are in assets.
